# LexRead-
作者在上完法律检索课程后，萌生开发法学论文阅读器的想法。LexRead 法学智能阅读工作台，是一款专为法学研究者设计的工具，旨在解决法律检索完成后，从阅读、摘录到写作过程中材料来源易丢失、研究思路易中断的难题。 它以“研究项目”组织文献、笔记与写作草稿。核心功能包括：在PDF内高亮并一键生成带有完整来源信息（文献、页码、上下文）的“研究卡片”；自动提取脚注信息并生成引注草稿，便于溯源核验；以及将写作草稿与研究卡片同屏陈列，实现“写作回查”。 LexRead不替代专业数据库的检索功能，而是专注于承接检索后的研究环节。它通过降低重新核验材料的成本，帮助研究者在阅读、笔记与写作的往返中，保留原文出处与研究判断，让法学研究的过程更清晰、可追溯。
